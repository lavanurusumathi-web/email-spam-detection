\# 📧 SmartMail – AI Spam Email Detection



SmartMail is an AI-powered email application that detects spam emails, connects with Gmail, and provides an AI Customer Care chatbot.



\## 🚀 Run the Project



\### 💻 Localhost



Run:



```bash

streamlit run app.py

```



Open:



\*\*http://localhost:8501\*\*

\* 📧 Gmail integration
